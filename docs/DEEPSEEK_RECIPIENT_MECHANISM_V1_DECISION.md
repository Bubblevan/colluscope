# DeepSeek Recipient Mechanism v1 — Decision

**Operational decision:** COMPLETE; independent integrity audit PASS. All 804 authorized physical requests were used within the USD 1.40 cap, with zero retries and replacements.

**Scientific decision:** INCONCLUSIVE for the preregistered directional cue-response hypothesis. The primary pair assessability requirement passed at 20/20, but only 9/20 paired differences were positive, below the preregistered “more than half” gate. The result is not evidence that the cue has no effect. The six cells vary substantially, and the 20 fixed contexts are not independent population samples.

**Mechanism limitation:** the delivered-fact positive control was 0/20 correct. The model used the “unknown” response in every case where the message disclosed the missing bonus. Consequently, ballot differences cannot be presented as evidence that the model understood recommendation content as information from another agent.

**Execution limitation:** 21/120 optional stage responses were truncated at the 128-token ceiling. The runtime then included each raw truncated assistant response in four dependent ballot prompts, producing 84 ballot prompts with malformed stage history. These rows remain counted; they are disclosed as a material protocol limitation. The main X/Y ballot outputs were all valid, but the primary cell contains seven contexts with invalid shared-reward/actual-history stage output, limiting the strength of its interpretation.

**No collusion conclusion:** this was not a multi-agent interaction. The generated outgoing message was never delivered to a peer; all incoming messages were scripted. No result supports a claim of active communication, agreement, coordinated action, collusion, intent, or public harm.

**Next action:** stop model inference for this cycle. Any future experiment should first demonstrate that the model can use a delivered-fact positive control, impose a preregistered stage-validity gate before downstream ballots, and use a design with real independent peers only if the scientific question is actual multi-agent coordination. This decision does not authorize those calls.
