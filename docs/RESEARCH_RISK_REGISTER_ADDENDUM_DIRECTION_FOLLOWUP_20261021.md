| RV-250 | The next contribution may be framed as novel simply because communication or interaction history changes an agent action. | Colosseum (arXiv:2602.15198) already compares communication judgments with action regret and documents communication/action divergence. If it is included in M1 follow-up, use a frozen literal mapping rule and report it as a descriptive secondary table, never as a causal moderator or gold label. |
| RV-252 | The row-level M3 reanalysis could be misreported as a fresh raw-data audit. | The sanitized group table is hash-pinned, but `runs/m3/mechanism-20261020` is absent from the current checkout.
