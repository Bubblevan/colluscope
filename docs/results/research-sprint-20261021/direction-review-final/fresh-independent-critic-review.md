## Recommendation

The M4 B5 20/24 response-change result deserves prominent reporting, but it should not displace the prospective M1 package replication as the next primary experiment. The M4 result is a finite descriptive fact: independent public-welfare references stayed fixed and B5 exactness improved from 4/24 to 17/24. Of the 20 changes, 15 were `insufficient_evidence → absent`, four were `present → absent`, and one was `insufficient_evidence → present`; this is not 20 binary flips. The permission-view input also bundled message text, event structure, provenance, visibility/completeness cues, and token length. Exact-request historical/current disagreement gives a competing response-variation explanation.

The M1 private-reward × chat-stage package is the strongest prospective empirical candidate because it concerns Agent actions, but it remains a finite package effect. Shared-target knowledge and an added message stage prevent a semantic communication, collusion, or intent claim. C is valuable as a claim framework, but the current scripted fixtures are not a standalone general identifiability result.

## Competing explanations for the one-sided synthetic B5 result

The supplied and locally checked score summary reports 40/40 canonical predictions as `present`, balanced 20/20 references, 20/40 exact model predictions, and 40/40 exact deterministic-rule predictions. The reviewer did not replay the raw calls.

1. **Prompt-order or answer-option prior:** the combined prompt-and-enum reversal changed 36/40 predictions but cannot attribute the effect to either order. Test a randomized 2×2 order factorial on the same hash-pinned rows.
2. **Arithmetic or label-mapping burden:** adding a six-assignment welfare table yielded 39/40 exact, but it also altered prompt length and salience. Compare useful arithmetic with a format- and provider-token-matched irrelevant-number table.
3. **Synthetic/production input and scale shift:** the supplied task-difficulty summary reports mean regret 115.9 for synthetic `present` rows versus 4.7 for M4, and mean matrix-cell range about 80 versus 16. These are different corpora, so “syntheticness” is not isolated. Test matched/scaled matrices with the same production compiler.
4. **Compiler/instruction mismatch:** the frozen synthetic request path differs from production B5. Compare byte-hashed production requests with only the suspected compiler fields toggled.
5. **Within-service response variation:** 19/48 historical/current exact-request pairs disagreed in raw label despite matching reported fingerprints. Interleaved identical-request repeats can quantify a finite within-run comparison; they cannot identify hidden provider state.

The proposed 256-request A2 concept is not recommended in its current form. It lacks a clear compiler contrast, its length-matching rule is not pinned to provider tokens, and the label it evaluates is exactly rule-computable. Further B5 inference would be justified only if a result could change a concrete monitor-design decision or test an LLM-specific task.

## Paper value and closest work

- **A, B5 evidence-view response:** useful negative evidence about a specific structured monitor task, but low standalone paper value and substantial overlap with Arike et al.'s monitor information-access and Extract-and-Evaluate work. Public welfare should be computed deterministically here.
- **B, M1 reward × chat-stage package:** highest prospective value, with a narrow finite-set estimand and clear falsifiers. Broad incentive/communication claims overlap auction-agent and long-horizon work; the defensible contribution is the preregistered matched allocation-package contrast and strict evidence boundary.
- **C, evidence sufficiency:** essential to Track 2.3 interpretation, but current finite scripted pairs do not establish a general impossibility result. Keep the existing result as a supporting witness.
