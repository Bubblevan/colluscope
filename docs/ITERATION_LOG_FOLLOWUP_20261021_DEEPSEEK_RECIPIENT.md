# DeepSeek Recipient Mechanism v1 — Execution Log

## Registration and offline gate

- **Date:** 2026-10-21 UTC.
- **INSPECT:** The prior M3 subgroup was post-hoc and the prior M1 evidence does not identify message semantics or active-peer causality. The new experiment must test one falsifiable recipient-side response while keeping X/Y public welfare and focal base score equal. Greatest runtime risks were dynamic token mismatch, relying on an unconfirmed first identity response after interruption, and silently treating invalid JSON as a valid ballot.
- **SPECIFY:** A counterexample is any X/Y/neutral full-prompt token difference; a model-history control token that changes the pinned chat template; a repeated prompt whose bytes differ; a nonempty text paired with `no_message`; or resumption after an identity attempt without a frozen identity. Any such case must stop or be scored invalid with no retry.
- **IMPLEMENT:** Frozen 20-context selector, 804-row schedule, official-tokenizer renderer/config, single-attempt DeepSeek runner, independent raw-response scorer, targeted regression tests, and the local-only research authorization/preregistration. X/Y repeat rows are exact byte-repeat controls. The raw run directory and tokenizer asset are ignored by nested local `.gitignore` files; the repository-level `.gitignore` was restored after `researchctl audit` showed it is itself a historical frozen input.
- **RUN:** Context selector produced 20 matrices, 10 focal A / 10 focal B, regret bands 7/7/6, and 804 unique request rows. Static token checks: ballot JSON 5 tokens, neutral history 5, each incoming message 9. All 120 context×reward×history full-prompt X/Y/neutral parity fixtures passed. Targeted tests: 4 passed. Research registry: 5 cycles, zero prior cycles open; current authorization reserves 804 calls / USD 1.40. Offline runner preflight passed with 0 model calls. These are software/protocol checks, not model-performance evidence.
- **Preserved initial failure:** The first design iteration found full-prompt incoming-message lengths 9/9/8 and failed token parity. The neutral wording was revised before preregistration; the original mismatched counts are retained here as a development failure, not hidden as a successful test. No model request was sent during that repair.
- **ADVERSARIAL REVIEW:** This remains a single model responding to scripted cues. Its outgoing stage text is not delivered to another agent. The alias/fingerprint do not pin immutable provider weights. Token equality does not remove wording/salience confounds. A positive cue response is neither semantic comprehension nor coordination, collusion, or intent.
- **DECIDE:** Registered for the user-approved bounded batch; run only after the freeze commit is pushed. Stop on request/identity/tokenizer/hash/privacy/cost failure; preserve every started and unstarted row. No Qwen or external fallback.
