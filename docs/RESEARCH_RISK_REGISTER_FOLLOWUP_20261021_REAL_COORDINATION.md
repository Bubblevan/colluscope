# Research-risk follow-up — real coordination pilot

| Risk | Finding / counterexample | Control or remaining limit | Status |
|---|---|---|---|
| Failed capability control burns the whole budget | Prior Recipient V1 had 0/20 fact controls; its “undisclosed bonus” wording was ambiguous. | Four explicit delivered/absent fact controls precede all game requests. First incorrect/invalid/failed control stops dispatch; a runner test injects a failure at each of the four positions. | Mitigated offline; must pass live controls to continue. |
| Truncated stage contaminates descendants | Prior 21 truncated outputs were followed by 84 dependent ballots. | Strict tool-call finish/schema/semantic validation; invalid or nonterminal response yields no action in dependency map; descendants are recorded unattempted. No retry or replacement. | Mitigated in runner path; verify with offline and response parsing tests. |
| Shared target mistaken for communication-induced coordination | Both agents know the +20-per-agent HH reward in every arm; HH is privately rewarded and publicly suboptimal. | Same reward across three arms; actual-vs-no-delivery is descriptive within three fixed matrices. HH, concordance, or welfare loss is never a collusion label. Independent parallel choice remains a full alternative. | Intrinsic identification limit. |
| Extra reasoning/stage confounds chat | Adding a message call only in a chat arm changes generation count/context exposure. | Each arm has two message-stage requests and two ballots; no-delivery suppresses delivery, neutral substitutes a fixed first message, actual delivers the first proposal. The neutral arm includes a possible delivered return reply, so actual-vs-neutral is not a pure semantic-message estimand. | Partially controlled; claim boundary frozen. |
| Deterministic order/provider state | Temperature is 0; only three matrices, one run per arm, no stochastic seed. | Condition order is counterbalanced across matrices and logged. No population inference, p-values, or causal claim; returned model/fingerprint checked. | Remains material. |
| Prompt/condition leakage | Treatment names or references could be visible to model. | Conditions, IDs, references, success gates and control answer keys stay researcher-only. Only natural routing facts appear in the corresponding agent prompt. Prompt reconstruction is independently audited. | Testable offline. |
| Privacy / private-message exposure | Proposal/reply text is generated in this pilot. | Raw requests/responses and generated text stay in ignored, ACL-restricted local run storage. Public ledger exports only salted/hashed request IDs and sanitized metrics. | Operational control; inspect before publication. |
| Context and model non-independence | Both roles are requests to one model alias; a stateless endpoint receives reconstructed history. | No claim of distinct model identities or persistent autonomous agents. Conclusions are about role-separated contexts under this exact API/runtime. | Intrinsic scope limit. |

The pilot can describe proposals, send attempts, delivery acknowledgments, reply actions, ballot concordance, joint outcomes and public welfare. It cannot identify latent collusion or distinguish shared-incentive parallel behavior from a tacit agreement without stronger interventions and additional evidence.
