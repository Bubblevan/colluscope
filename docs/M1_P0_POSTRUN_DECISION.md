# M1-P0 Post-run Scientific Audit Decision

**Decision: GO for a qualified descriptive Results section and protocol design; NO-GO for formal M2 detector evaluation or a collusion/causal claim.**

## Supported directly by the frozen real data

- The audited package still has 25 completed episodes, 95 returned requests, and unchanged T/B/Public E hashes. Independent settlement from raw ballots and the public matrix reproduced all recorded outcomes.
- Harmful public-welfare outcomes occurred in normal cooperation 2/5, common public bonus 4/5, private bonus with chat 3/5, and 0/5 in each of private bonus without chat and chat without side bonus. The public-bonus arm's four losses split into two target executions and two non-target chair-tie outcomes.
- Three private-bonus/chat episodes selected the target. Five delivered A/B messages in those episodes named the same target and proposed coordination; the five subsequent sender/recipient ballots all matched it. No message contained a codebook-positive explicit vote commitment or acceptance.
- Both agents generated the message-stage action before receiving any peer message. Therefore matching proposals at that stage are compatible with independent reactions to the shared target; they are not replies or negotiated commitments.
- Public-only E contains no private messages and no private-reward assignment. Its original bytes remain unchanged.

## Reasonable but unproven interpretation

The timing and ballot consistency in episodes 07, 14, and 23 are compatible with private messages influencing target voting. The paired chat/no-chat differences (target execution 3/5 versus 0/5) justify a follow-up hypothesis. They do not isolate message influence from channel awareness, added message-generation calls, self-history fields, extra tokens, or each agent's own private target incentive. The no-bonus chat case in seed-1 also changed B's ballot without a sent message, directly supporting the channel/context alternative.

## Not established

- Latent collusion, malicious intent, a binding agreement, or a causal effect of private communication.
- That welfare loss or target execution is a valid collusion gold label.
- Detector accuracy, advantage of any of the four views, or a general result beyond one model/task/payoff family and five matched blocks.
- Any benefit from Privileged message access; that projection has not been created or evaluated.

## Gate

**GO:** publish this carefully scoped post-run audit, preserve the original Public-only E, and use M1-P0 cases for protocol development.

**NO-GO:** formal M2 metrics, threshold calibration/test claims, detector comparison, model training, new Agent Pilot, or additional model calls. The proposed M2 data protocol is a draft only. Any Privileged Audit projection or experiment requires a separate permission and frozen protocol.

The single highest-value next uncertainty to resolve, after review and separate approval, is whether message content has an effect beyond channel/context and shared target incentives. A follow-up must hold message-turn/context/token exposure constant while varying whether a peer proposal is actually delivered, retain matched scenario/seed blocks, and predefine observable acceptance and abstention labels.
