# Research Risk Register Addendum — Existing Profile Analysis (2026-10-21)

| Risk | Evidence / severity | Required treatment |
|---|---|---|
| Same-input Public-only response instability can masquerade as view sensitivity | **High.** In 23 unique exact Public-only request profiles, only 7 had unanimous historical/current labels; 16 were non-unanimous. Exact request bytes and matching reported fingerprints were independently checked, but runs were not simultaneous. | Keep B5 context claims descriptive and `INCONCLUSIVE`; do not call this randomness or a causal view effect. State that same-window variation, provider-state drift, and view changes remain unresolved. |
| Duplicate contexts inflate apparent sample size | **High.** One Public-only profile maps to two contexts and has four retained observations. | Use 23 unique profiles for the primary descriptive cluster unit, and show 24 assigned contexts as a secondary denominator. Never drop the duplicate or count it as two independent inputs. |
| Rule-computable target misrepresented as LLM monitor contribution | **High.** Public welfare labels can be recomputed deterministically from the public matrix, ballots, tie-break rule, and outcome. | Retain a deterministic reference baseline; do not claim the B5 label needs an LLM. Move prospective work toward an Agent package question or independently coded natural-language evidence task. |
| Repeatability-v2 scope may have low incremental information | **Medium-high.** Existing cross-run repeats already reveal substantial exact-input disagreement, though not within-run variance. | Deprioritize the 144-call candidate unless same-window repeatability is a primary claim and a fresh protocol shows how the result changes the paper. The existing data do not count as a run of that candidate. |
| M1 package contrast can be overread as semantic communication or collusion | **High.** The private-target reward and extra chat stage are assigned together in the target package, while A/B share knowledge of the rewarded target. | If approved, claim only the finite `private reward × chat-stage package` interaction on the frozen 24-matrix set. Keep parallel behavior, failures, all 120 assignments, and family-specific results; do not infer message meaning or intent. |
| New model-call authority may be inferred from old DeepSeek grant | **High.** The 232-call `m4-b5-context-sensitivity-campaign-v1` approval is consumed and experiment-specific. | Require a new approval for M1/Qwen. Do not transfer the DeepSeek grant or its remaining project-wide balance. |

The analysis is post-hoc and has not received a separate independent scientific-critic review. The supporting response bytes remain in Git-ignored local run directories; committed outputs contain hashes and aggregate counts only.
